# Netcat-alternative-for-learning

This project was created for learning purposes. The goal is to understand how TCP connections work, how to receive data, and how to communicate over a network.

Features
TCP listening
Custom IP and port
Incoming connection detection
Receive data from clients
Telnet support for testing
Usage

Run the script:

bash
sudo python3 netcat.py


Enter your IP address and port when prompted.

You can connect using Telnet:

bash
telnet 192.168.0.126 9999


After connecting, type a message and send it to the server.
